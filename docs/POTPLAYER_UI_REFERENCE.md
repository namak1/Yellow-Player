# Interface reference and design

Reference: official PotPlayer page and its product feature imagery. Exact window screenshots and all settings dialogs were not inspected; do not claim pixel parity.

Yellow Player uses original assets: graphite shell, warm yellow play mark, compact transport below an uninterrupted video stage, right playlist, accessible subtitle drawer, tabbed preferences, context menu and timed OSD. Empty state clearly offers local file opening; no fabricated movies/history. Mobile collapses sidebar and wraps controls. Fullscreen is applied to the stage wrapper so subtitle overlays remain inside it.
