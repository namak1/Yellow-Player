# Yellow Player keyboard contract
These are implemented Yellow Player shortcuts, not a certified complete PotPlayer keymap. Community references disagree on synchronization direction; explicit Yellow convention takes precedence.

| Key | Action |
|---|---|
| Space | Play / pause |
| Left / Right | Seek 5 seconds |
| Shift + Left / Right | Seek 30 seconds |
| Up / Down | Volume by 5% |
| M | Mute |
| Enter / F | Fullscreen |
| F3 / Ctrl+O / Cmd+O | Open media |
| F5 | Preferences |
| F6 | Playlist |
| L | Subtitle panel |
| , / . | Subtitles 500ms earlier / later |
| / | Reset subtitle delay |
| X / C | Slower / faster |
| Z | Normal speed |
| B | Bookmark |
| Escape | Close dialog |

Text inputs/selects/contenteditable areas suppress player shortcuts. Browser and OS reserved keys may override these.
