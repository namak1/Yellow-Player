# Menu structure
Proposed Yellow Player organization inspired by PotPlayer, not an exact recovered current menu tree.

- Open: local files, subtitles, URL.
- Playback: play/pause, stop, speed, seek, repeat, A/B, bookmarks.
- Subtitles: tracks, secondary track, appearance, synchronization, cue browser.
- Video: aspect, fit, rotation, flip, brightness, contrast, saturation, capture.
- Audio: volume, mute, equalizer.
- Playlist: filter, move, remove, export, clear.
- Preferences: appearance, subtitles, playback; persistent local settings.
- Information: file dimensions, duration, size, browser errors and limitations.

Official history confirms customizable context menus. Full nested proprietary menu enumeration remains pending desktop inspection.
