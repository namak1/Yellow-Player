# Research sources — 23 October 2026

Research baseline, not a claim of exhaustive inspection of every proprietary dialog. No Windows PotPlayer instance was available. Menu wording and shortcut mappings need verification against a running current installation.

- S1 https://potplayer.tv/ — official product page; hardware acceleration, subtitles, bookmarks, devices, 3D and renderer capabilities.
- S2 https://t1.daumcdn.net/potplayer/PotPlayer/v4/Update2/UpdateEng.html — official release history; latest observed release 261021. Historical additions do not guarantee identical current UI placement.
- S3 https://mpv.io/manual/stable/ — native engine command, property, track, filter and subtitle API.
- S4 https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats — browser/container/codec distinctions.
- S5 https://github.com/libass/JavascriptSubtitlesOctopus — mature browser ASS rendering candidate, workers/WASM/fonts and disposal.
- S6 https://v2.tauri.app/start/ — native shell candidate.
- S7 https://ffmpeg.org/legal.html — build-dependent LGPL/GPL/nonfree requirements; not a distribution clearance.
